# Mistborn Deckbuilder

Adaptación digital en desarrollo para jugar a Mistborn Deckbuilder con amigos a distancia, usando Godot 4.x y GDScript.

Alcance confirmado: competitivo de 2–4, cooperativo de 2–4 y cooperativo en solitario; idioma español. Reglamento de referencia recibido y documentado; su archivo está en inglés y el catálogo completo sigue pendiente.

La primera versión será una aplicación para Windows, sistema disponible para todos los participantes.

Actualmente solo existen un cargador JSON y dos cartas de prueba. Todavía no hay un proyecto Godot ejecutable ni una partida jugable. Consulta el [estado actual](docs/estado-actual.md) antes de intentar ejecutarlo.
