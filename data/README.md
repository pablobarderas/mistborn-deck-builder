# Catálogo de trabajo

cartas.json contiene exclusivamente dos muestras heredadas, migradas al contrato de P06; no son cartas oficiales verificadas. Los IDs se conservan para trazabilidad, no para declarar equivalencia con los diseños físicos.

Ver [contrato](../docs/datos-de-cartas.md), [captura por lotes](../docs/captura-de-cartas.md) y [SPEC-006](../docs/specs/006-contrato-catalogo/spec.md). No copiar automáticamente valores de la maqueta P05 al catálogo.
